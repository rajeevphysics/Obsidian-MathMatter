# Definition 
The rank of a [[Matrix Notation|matrix]] is the number of [[Leading 1s|leading 1s]] in its [[Row Echelon Form|row echelon form]] (not necessarily [[Reduced Row Echelon Form|RREF]]). The rank describes the number of [[Linear Independence & Dependence|linearly independent]] [[Row & Columns Vectors|column vectors]] in a matrix. A matrix in [[Row Echelon Form|REF]] or [[Reduced Row Echelon Form|RREF]] will always have a rank greater than 1. Upset the [[Zero Matrix|zero matrix]], which has a rank of 0. If a matrix is denoted as $A$, the rank of the matrix is denoted as $\text{rank(A)}$

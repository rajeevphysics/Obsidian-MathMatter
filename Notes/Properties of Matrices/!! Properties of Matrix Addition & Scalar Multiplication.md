
# Definition 
Properties of [[Matrix Addition & Scalar Multiplication|matrix addition and scalar multiplication]] are assumed properties that are allowed to be performed on a matrix. The axioms are assumed to be true because it's assumed that two matrices can be added together and a scalar can be multiplied by a matrix. So that if $A,B$ were matrices and $s$ was a scalar, then $A+B$ and $sB$ are valid. 


# Axioms
> [!warning] Assumptions 
To show the following axioms, assume the following:
> - [[Matrix Notation|Matrices]] $A,B,C$ are matrices **with the same size** ($A,B,C \in \mathbb{R}^{m\times n}$)
> - By the definition of matrix addition, $A+B$ are valid 
> - [[Scalar & Vectors|Scalars]] $c,d$ is a [[! Real Numbers|real number]] ($c,d\in \mathbb{R}$)
> - By definition and [[Matrix Addition & Scalar Multiplication|matrix scalar multiplication]] $cA$ is valid
